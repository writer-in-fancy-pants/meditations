EEG · PPG muselsl

Muse 2

Alpha/theta Peniston protocol training and HRV coherence biofeedback via Muse 2's EEG and PPG sensors. Requires the muselsl bridge.

  • α/θ crossover training with adaptive Peniston threshold
  • PPG-derived HRV via Welch peak detection at 64 Hz
  • Live band-power chart across all 4 EEG channels
  • Generative ambient audio + closed-eyes tone feedback

HRV · BLE Bluetooth

WHOOP

Resonant-frequency HRV biofeedback from WHOOP's BLE heart rate broadcast. Connects directly in Chrome/Edge — no Python required — or via bridge.

  • Direct Web Bluetooth — no Python, no bridge in Chrome/Edge
  • Rolling RMSSD, pNN50, and coherence index gauge
  • Adaptive volume + pitch-coded tones for closed-eyes use
  • Session duration, end alarm, and session summary
